Is this fertilizer genuine?

Type the code from the label on the bag. You will know in a few seconds, before you pay or plant.

Check a bag

How the check works

  1. 1
    Every genuine bag has its own codePrinted for that bag only, when the factory registers the batch.
  2. 2
    The first phone to check a code owns itIf the same code turns up on another bag, you are warned it was copied.
  3. 3
    Bad batches are stoppedWhen a batch fails a lab test or is recalled, the check says so, and farmers who got it are sent an SMS.

No smartphone? Send the code by SMS to your cooperative's AgriProof number.
